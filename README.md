# learning-apollo

带你走进 Apollo 自动驾驶！

## 关于 Apollo

[Apollo](https://github.com/ApolloAuto/apollo) 是百度开源的高性能、灵活的自动驾驶平台，旨在帮助开发者快速构建自动驾驶系统。它包含了感知、定位、规划、控制等完整的自动驾驶模块。

## 资源说明

本仓库包含以下学习资源：

- **dig-into-apollo-book.pdf** — 《深入理解 Apollo》电子书，系统性地讲解 Apollo 自动驾驶平台的架构、核心模块与实现细节。

## 快速开始

### 1. 获取 Apollo 源代码

```bash
git clone https://github.com/ApolloAuto/apollo.git
```

### 2. 下载《深入理解 Apollo》电子书

该书源自 [dig-into-apollo](https://github.com/daohu527/dig-into-apollo) 项目，本仓库已包含该 PDF 文件，可直接阅读。

## 学习路线建议

1. 先通读《深入理解 Apollo》，建立对 Apollo 整体架构的认知
2. 结合 Apollo 源码深入理解各模块的实现
3. 动手运行 Apollo 仿真环境，实践所学内容
